# Named controller drawings

Copies of the Gamepad Asset Pack silhouettes in `../library/` in which the
buttons, sticks and d-pad carry their logical input as `id` and Inkscape layer
name (`SOUTH`, `LEFT_STICK`, `DPAD`...), so the main window can light them up
where they are drawn. Only those attributes differ from the originals (a test
checks it); the originals stay unmodified next to the upstream manifest.

Made with Name inputs and Auto-detect in pawz. Derived from the Gamepad Asset
Pack by Al. Lopez (AL2009man), MIT licence: see `../Gamepad-Asset-Pack-LICENSE.txt`.
